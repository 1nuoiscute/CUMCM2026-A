# 复现说明

## 环境与运行

Python 3.13.13；本次环境依赖见 `requirements-tested.txt`。从仓库根目录执行 `python run.py all`。
运行入口使用当前 Python 解释器，自动采用无窗口绘图，并将每问标准输出和错误写入 `outputs/logs/`。

`python run.py q1`、`q2`、`q3`、`q4` 可单独运行；建议依次执行。Q4 的跨问题比较会读取 Q3 摘要；缺失时原程序使用内置参考值。
`python run.py validate` 运行提交版 Q3/Q4 验证程序，须先生成 Q4 摘要，且耗时可能明显长于单问。

## 输出

每问结果、图和中间文件写入 `outputs/qN/`。重复运行覆盖这些生成文件，不覆盖 `results/submitted/`。
Q1/Q2 自带部分数值比较；独立 Q3/Q4 验证脚本包含更多网格、步长和守恒检查。

## 已知限制

- 论文作为历史提交版本保留；不会用重跑输出替换提交表或修改论文数值。
- 图片中的中文依赖本机中文字体，Windows 优先使用微软雅黑/黑体。缺少中文字体可能出现警告或缺字，不影响数值求解。
- 模型假设、适用范围和赛题给定参数见论文；数据驱动的收缩关系仅在该题观测条件下验证。
- 尚未验证 macOS/Linux，也未在全新虚拟环境中安装验证。记录的依赖版本来自本次 Windows 环境。
